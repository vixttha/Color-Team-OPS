# Verified primary sources and repository provenance — checked 2026-10-30

**Primary definitions / standards**
1. April Wright, Black Hat USA 2017, "Orange is the New Purple": https://blackhat.com/us-17/briefings.html — explicit Yellow-development, Red+Yellow Orange, Blue+Yellow Green, Green forensic/detection visibility. Caution: a proposal/model, not a global nine-color standard.
2. NIST NICE playbook: https://www.nist.gov/itl/applied-cybersecurity/nice/nice-framework-resource-center/playbook-workforce-frameworks — explicit distinction between jobs and work roles.
3. NIST on jobs vs roles: https://www.nist.gov/itl/applied-cybersecurity/nice/nice-framework-resource-center/resources/occupations-jobs-and-work — detail on job titles vs work roles.
4. NIST White Team glossary: https://csrc.nist.gov/glossary/term/white_team — neutral exercise governance, rules and adjudication.
5. NIST "Building a Competition": https://www.nist.gov/document/building-cybersecurity-competition — Black support, Gold/White admin, Orange/Green users (a different context); caution PDF should be visually verified when analyzing detailed pagination.
6. NCCDC 2026 rules: https://nationalccdc.org/rules.html — Black competition ops, Gold support/communications, White judges, Orange customers. Direct counterexample to 'Gold universally means CEO'.
7. NIST SSDF: https://csrc.nist.gov/pubs/sp/800/218/final — secure software development practices, supply chain and provenance.
8. OWASP ASVS: https://asvs.owasp.org/ — testable web application security controls.
9. OWASP DevSecOps guideline: https://owasp.org/projects/devsecops-guideline — CI pipeline, secret scanning, SAST, SCA, IaC, DAST and secured SDLC.
10. MITRE ATT&CK: https://attack.mitre.org/resources/ — observed adversary behaviors for threat-informed intelligence and testing.
11. GitHub branch protection docs: https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches/about-protected-branches — trusted checks / branch rules.

12. Jobs and Skills Australia, Software Engineer occupation profile: https://www.jobsandskills.gov.au/data/occupation-and-industry-profiles/occupations-osca/273333-software-engineer — directly recognizes Software Engineer work and illustrative specializations (AI Engineer, Backend / Full Stack / Database developer, etc.). It **does not** associate these roles with cybersecurity colors.
