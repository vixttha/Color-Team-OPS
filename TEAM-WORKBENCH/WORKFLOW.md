# GREEN one-lane work loop

1. HEAD: re-read permission, latest home/integration SHAs and backlog; select one bounded same-specialist task and evidence criteria.
2. GREEN WORKER: perform only GREEN-domain work in home write scope, cite exact sources; no role switching.
3. VALIDATE: independently re-read code/tool observation and source SHA; authored tests are NOT executions.
4. LOGICAL INTERNAL AUDITOR: challenge evidence, security, assumptions, scope and regression risks. This is a distinct logical check, not externally authenticated review or White Team.
5. HEAD: accept, bounded repair (maximum two), defer, block, send INCALL to another team, stop and save handoff.

One active item, no fabricated recurring execution, stop on stale/ref conflicts, unsupported tools or exhausted budget. Never force-push.
