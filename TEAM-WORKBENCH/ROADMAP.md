# YELLOW rolling roadmap — multi-week/month capability

1. **Bootstrap:** read team charter and all prior findings/queues, refresh live repo, read INCALL.
2. **Baseline:** build source-SHA-indexed specialty inventory, prioritized by release blocker and real owner criteria.
3. **Deep cycles:** execute one bounded YELLOW item at a time; source-linked diff/reports, distinct Validate and logical Auditor checks.
4. **Cross-team feedback:** message applicable colleagues through their INCALL GitHub issues; never switch identity silently.
5. **Promotion:** send only a minimal, testable Head-ready recommendation/patch to Development HQ; integration writer revalidates at its new SHA.
6. **Maintenance:** periodically refresh threat/coverage/bugs/CI and exact-source impact **when invoked**. Archive sessions rather than overwriting history.

**Team specialty focus:** implementation architecture, backend/frontend/API integration, schema and tests, performance and regression quality. Long-lived plan does NOT mean 24/7 agent execution or weekly work absent a scheduled/authorized invocation.
