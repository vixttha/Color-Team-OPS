# Months or years of work without fake autonomy

At each *real* invocation: (1) read prior handoff/queue, (2) re-observe live GitHub refs/permissions, (3) scan INCALL issue comments, (4) expire old evidence/compare code drift, (5) select one bounded specialist task, (6) execute under authority, (7) Validate and logical Internal Audit, (8) commit an append-only dated session record and update state/queue, (9) record next exact steps. A weekly/monthly review is a **plan** until an automation or owner invocation actually runs it.

Use stable item IDs `<COLOR>-W0001`, finding IDs `<COLOR>-F0001`, session IDs `<COLOR>-YYYYMMDD-001`, message IDs `IN-<TO>-YYYYMMDD-NNN`. Keep old records; mark superseded with pointer, do not rewrite historical observations as current truth. Maintain history with links to immutable commits. Handle concurrent writes with optimistic SHA/lease and rebase/reconcile rather than force. Force-push is forbidden by template default.

Stop and persist truthful PARTIAL/BLOCKED handoff when a tool isn't available, tokens/time exhausted, or authority changes. Multi-month records are not equivalent to continuous autonomous operation.
