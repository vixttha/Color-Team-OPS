# v0.0.1 acceptance / audit

## Must pass before publishing

- [ ] Manifest and each of twelve skill frontmatters valid; exact version 0.0.1; no invalid package wrappers.
- [ ] The nine role skills and three coordination skills are present.
- [ ] Product laws appear in canonical constitution and each skill references them.
- [ ] No local runtime dependency, stdio server, localhost endpoint, self-hosted runner invocation, hidden action or automatic paid service.
- [ ] Each skill describes truthful outputs when tools or evidence are unavailable.
- [ ] JSON mission, event and decision schema examples parse and validate.
- [ ] Stale source SHA, nonexistent evidence, no-progress loops, unauthorized actions and unsupported hosts fail closed conceptually.
- [ ] Create a PRIVATE installed plugin through Plugin Creator and inspect reported files.
- [ ] GitHub source recorded in an isolated v0.0.1 branch; no automatic merge or runner use.

## Not claimable at v0.0.1

Real unattended background execution, automatic completion triggers, guaranteed host transfer, authenticated independent review, real GitHub change verification by this plugin, or reliable 24/7 continuity. These require additional cloud APIs and deployment; skills alone are not a runtime.
