# Audit: previous v0.1 prepared source -> v0.0.1

**Critical replaced:** proposed singleton local worker, local SQLite WAL, local coding adapters, local-test action, locally required services and hardware dependencies. None are required or bundled in v0.0.1.

**Critical clarified:** No skills-only plugin can guarantee infinite autonomous completion-triggered dispatch across browser sessions; explicit hosted cloud backend and per-host integrations are future requirements. Current skills only recommend bounded routing inside a supported host run.

**High clarified:** Old routing demonstration only compared claimed verifier identity/digest and did not authenticate proof; updated design refuses to call such checks verified without trust anchors.

**High fixed in policy:** Local self-hosted GitHub runners, though available on an unrelated branch, are never a prerequisite and never a default fallback. v0.0.1 has no workflows or local runner execution.

**Medium fixed:** Site compatibility advertised conditionally, not as universal automatic import; no provider-specific tool IDs assumed; no silent privilege escalation.

**Residual limitations:** no remote stateful engine, independent trusted CI, source writer or hosted MCP; therefore planning-only/in-session workflows until a cloud service is provisioned.
